# College-Results-Management-System
Initial release of the College Results Management System developed using C.

Features included:
• Faculty login and dashboard
• Student login and dashboard
• Student details
• Internal Marks 1 and Internal Marks 2
• Semester 1 and Semester 2 results
• SGPA and CGPA calculation
• Pass/Fail result status
• Central library information
• Placement details and packages
• College notifications
• List of holidays with "NO DATA AVAILABLE" message

The project demonstrates the use of C programming concepts such as structures,
arrays, strings, loops, conditional statements, and user input handling.

This is the initial version of the project.
